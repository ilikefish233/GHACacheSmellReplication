This supplement reports the unified, version-balanced models for the 30-day RQ2 cohort. Duration uses weighted linear regression of log seconds; success uses a weighted linear probability model (LPM). All reported SEs are repository-clustered sandwich estimates with a $G/(G-1)$ correction. Duration tests use the normal reference; success tests use $t(G-1)$. Pointwise 95\% intervals are not multiplicity-adjusted. BH-FDR is applied separately to the 10 estimable CCS coefficients per primary endpoint; control-variable $p$-values are unadjusted. S9 has no exposure and is not estimable. No bootstrap resampling is used. Continuous size controls are log1p-transformed and standardized over the distinct version--event--week design rows, not over CCS-specific samples. Reference categories are role: other; ecosystem: none identified; OS: Linux; hosting: GitHub-hosted; event: push; week bin: 3 (seven-day bins anchored on 10 May 2026). Unknown and mixed categories remain in the models.
